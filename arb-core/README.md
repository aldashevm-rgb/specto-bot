# arb-core

Ядро спортивного **арбитража**: сканирует линии букмекеров, находит **вилки
(surebet)** — комбинации коэффициентов, где ставка на все исходы даёт
гарантированную прибыль независимо от результата, — и обогащает их **ИИ-разбором
матча**: кому нужнее победа (турнирная мотивация) и какой исход вероятнее.

> Отдельный модуль внутри репозитория, не связан с WhatsApp-ботом SPECTO.

## Как это работает

```
The Odds API ──► normalize ──► arbitrage ──► scanner ──► вилки + ИИ-разбор
(коэффициенты)   лучший коэф.   Σ(1/odds)<1               (ранжировано)
                 на исход                       ▲
API-Football ───────────────────────────────────┘
(форма/таблица)          motivation (Claude): кому нужна победа, вероятный исход
```

1. **normalize** — из линий всех БК берёт лучший коэффициент по каждому исходу.
   Рынки: `h2h` (1X2), `totals` (тоталы) и `spreads` (форы). Для тоталов/фор
   арбитраж считается строго в пределах одной линии (Тотал 2.5 ≠ Тотал 3.0;
   форы — зеркальная пара хозяева @−h / гости @+h).
2. **arbitrage** — если `Σ(1/odds) < 1`, это вилка; считает раскладку ставок с
   равной выплатой и гарантированную маржу/ROI.
3. **motivation** — Claude оценивает «кому нужнее победа» и вероятности исходов
   (П1/Х/П2), а `valueEdges` сравнивает прогноз с линией (перевес = `p·odds − 1`).
4. **scanner** — связывает всё, отдаёт список вилок (сорт. по марже), шлёт
   уведомления в Telegram и логирует находки в Supabase.

## Уведомления и лог

- **Telegram** (`notify/telegram.js`) — при вилке с маржой ≥ `ARB_NOTIFY_MARGIN`
  шлёт сообщение в чат/канал. Нужны `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
- **Supabase** (`store/supabase.js`) — пишет находки в таблицу `arb_surebets`
  (схема — `schema.sql`, применить в SQL editor). upsert по (event, market,
  line) — повторный скан не плодит дубли. Нужны `SUPABASE_URL` и
  `SUPABASE_SERVICE_ROLE_KEY`. Позже можно сверять ИИ-прогноз с результатом.

Оба слоя опциональны: без ключей сканер просто ищет и печатает вилки.

## Запуск

Node.js 18+.

```bash
cd arb-core
cp .env.example .env     # вписать ODDS_API_KEY (и по желанию API_FOOTBALL_KEY, ANTHROPIC_API_KEY)
npm run scan             # скан ближайших событий (upcoming)
npm run scan soccer_epl  # конкретный вид спорта / лига
```

Без `ODDS_API_KEY` скан не запустится (нужны реальные коэффициенты). Без
`ANTHROPIC_API_KEY` вилки всё равно находятся — просто без ИИ-разбора.

## Тесты

```bash
npm test    # node --test — чистая математика вилок, нормализация, разбор ИИ
```

Тесты покрывают ядро без сети (детект вилок, раскладка ставок, нормализация
линий, парсинг ответа модели, расчёт value-перевеса).

## Структура

```
src/
  config.js              переменные окружения, наличие ключей
  index.js               CLI: скан и печать вилок
  sources/
    oddsApi.js           The Odds API — коэффициенты БК
    apiFootball.js       API-Football — форма, таблица (контекст для ИИ)
  core/
    normalize.js         линии БК → лучший коэф. на исход (h2h/totals/spreads)
    arbitrage.js         математика вилок и раскладки ставок (чистая)
    motivation.js        ИИ-разбор матча (Claude) + расчёт value-перевеса
    scanner.js           оркестратор: коэф. → вилки → ИИ → уведомления/лог
  notify/
    telegram.js          уведомления о вилках в Telegram
  store/
    supabase.js          лог находок в Supabase (PostgREST)
  util/
    http.js              fetch с ретраями и таймаутом
schema.sql               таблица arb_surebets для Supabase
test/                    node --test
```
