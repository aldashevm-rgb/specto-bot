# Автоставка через Betfair (с подтверждением)

Вотчер может присылать value-ставки **с кнопкой «✅ Поставить»**. Нажимаешь —
бот ставит ровно эту ставку на бирже **Betfair** через официальный API, размер —
по Кельли. Работает **только для пиков у Betfair** (у обычных контор автоставка
запрещена их правилами).

> ⚠️ **Реальные деньги.** Всё сделано с тормозами и по умолчанию **выключено** и
> в **DRY-RUN**. Реально ставки идут ТОЛЬКО когда `BETTING_ENABLED=1` **и**
> `BETTING_DRY_RUN=0`. **Сначала обкатай на dry-run и мелких суммах.**

## Тормоза (защита банка)

| Переменная | Смысл | По умолчанию |
|---|---|---|
| `BETTING_ENABLED` | мастер-выключатель автоставки | выкл |
| `BETTING_DRY_RUN` | 1 = только «поставил бы», не ставит | **1 (dry-run)** |
| `BETTING_MAX_STAKE` | потолок на одну ставку | 20 |
| `BETTING_DAILY_CAP` | дневной лимит суммарно | 100 |
| `BETTING_CONFIRM_TTL_MIN` | сколько действует подтверждение | 15 мин |

Подтверждение с истёкшим сроком не сработает (коэффициент к тому моменту уходит).

## Настройка

1. **Ключ Betfair.** Заведи Application Key на
   [developer.betfair.com](https://developer.betfair.com) (нужен аккаунт Betfair
   с депозитом). Понадобятся `BETFAIR_APP_KEY`, логин и пароль.
2. Добавь в переменные (локально в `.env`, на Railway — во вкладку Variables):
   ```
   BETTING_ENABLED=1
   BETTING_DRY_RUN=1          # начни с dry-run!
   BETTING_MAX_STAKE=20
   BETTING_DAILY_CAP=100
   BETFAIR_APP_KEY=...
   BETFAIR_USERNAME=...
   BETFAIR_PASSWORD=...
   ```
3. Перезапусти вотчер. В логах появится:
   `Автоставка: ВКЛ — DRY-RUN (реальные деньги НЕ трогаются). Лимит 20/ставка, день 100.`

## Как проверить (обязательно перед реальными деньгами)

1. Оставь `BETTING_DRY_RUN=1`. Дождись value-ставки у Betfair → в Telegram
   придёт алерт с кнопкой **✅ Поставить**.
2. Нажми кнопку. Бот ответит: `🧪 DRY-RUN — поставил бы X …` (деньги не тронуты).
3. Убедись, что суммы и матчи адекватны, **несколько раз**.
4. Только потом, осознанно: `BETTING_DRY_RUN=0` + маленькие `BETTING_MAX_STAKE`
   (напр. 2–5). Проверь, что ставка реально появилась в аккаунте Betfair.
5. Дальше повышай лимиты по своему усмотрению.

## Важно понимать

- Ставится **только по твоему нажатию** — авто-размещения без подтверждения нет.
- Сопоставление матча с рынком Betfair — по названиям команд и времени; в редких
  случаях может не найти рынок (тогда придёт «рынок/исход не найден» — ничего не
  поставится). Это ещё причина держать dry-run, пока не убедишься.
- Ставки — риск. Инструмент не гарантирует прибыль; лимиты защищают от крупных
  потерь, но не от проигрыша отдельных ставок.
