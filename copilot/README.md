# Copilot — свой кодинг-ассистент

Свой аналог GitHub Copilot / OpenAI Codex на базе **Claude API**. Один общий
движок-агент, два интерфейса: **веб-панель** и **CLI**. Ассистент работает прямо
в репозитории: читает и правит файлы, ищет по коду, запускает команды.

## Как это устроено

Модель Claude — «мозг», вокруг неё построен агентный цикл:

```
запрос → модель думает → вызывает инструмент → видит результат → продолжает → ответ
```

```
copilot/
  core/
    client.js   Клиент Claude Messages API (стриминг, сборка content-блоков)
    tools.js    Инструменты: read/write/edit файлов, list, search, bash
    agent.js    Агентный цикл + системный промпт
  cli.js        Терминальный REPL
  server.js     Веб-панель (HTTP + SSE-стриминг)
  web/index.html  Чат-интерфейс
```

## Инструменты агента

| Инструмент | Что делает |
|---|---|
| `read_file` | Читает файл с номерами строк |
| `write_file` | Создаёт / перезаписывает файл |
| `edit_file` | Точечная замена фрагмента текста |
| `list_files` | Список файлов по glob-шаблону |
| `search` | Поиск по содержимому (regex) |
| `run_bash` | Команды: сборка, тесты, git |

Файловые операции ограничены рабочим каталогом — агент не выходит за пределы проекта.

## Запуск

Нужен `ANTHROPIC_API_KEY` (тот же, что для основного бота).

```bash
export ANTHROPIC_API_KEY=sk-ant-...

# CLI (интерактивно)
npm run copilot
#   команды: /reset — сброс истории, /exit — выход

# CLI на другом каталоге
node copilot/cli.js /path/to/project

# CLI, одноразовый запрос
node copilot/cli.js -p "найди все TODO в проекте и покажи их"

# Веб-панель → http://localhost:4000
npm run copilot:web
```

## Настройки (переменные окружения)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | Ключ Claude (обязательно) |
| `COPILOT_MODEL` | `claude-opus-5` | Модель |
| `COPILOT_EFFORT` | `high` | Уровень усилий: low/medium/high/xhigh/max |
| `COPILOT_ROOT` | текущий каталог | Рабочая область (веб-панель) |
| `COPILOT_PORT` | `4000` | Порт веб-панели |

## Что можно добавить дальше

- Память между сессиями (файл `.md` или Supabase — как в основном боте).
- Утверждение опасных команд (подтверждение перед `run_bash`/`write_file`).
- Подсветка diff при правках, история чатов в БД.
- Интеграция кнопкой в существующий дашборд `/hot`.
