# Copilot — свой кодинг-ассистент (дёшево / бесплатно)

Свой аналог GitHub Copilot / Codex на **любой модели**. Один движок-агент, два
интерфейса (веб-панель + CLI). Работает в репозитории: читает и правит файлы,
ищет по коду, запускает команды.

## Гибрид: бесплатно + умно по требованию

«Мозг» подключается модульно. Схема по умолчанию — **гибрид**:

- **Основная модель — локальная (Ollama), бесплатно.** Никаких токенов, никакой
  подписки, всё на твоём ПК. Подходит для большинства задач.
- **Сильная модель (Claude) — по требованию**, только для сложного: команда
  `/hard` в CLI или галочка «🧠 умнее» в веб-панели. Платишь только за эти
  запросы (центы), подписки нет.

Так основная работа — 0₽, а мощь топовой модели включается точечно.

## Быстрый старт на Windows (PowerShell)

Ты в PowerShell — тут команды отличаются от Linux (`export` не работает).

**1. Поставь программы** (один раз):
- [Node.js LTS](https://nodejs.org) — среда запуска.
- [Git](https://git-scm.com/download/win) — чтобы скачать проект.
- [Ollama](https://ollama.com/download) — локальные модели бесплатно.

**2. Скачай проект и зайди в папку:**
```powershell
git clone https://github.com/aldashevm-rgb/specto-bot.git
cd specto-bot
npm install
```

**3. Скачай локальную модель для кода** (один раз, ~5 ГБ):
```powershell
ollama pull qwen2.5-coder:7b
```
> На мощной видеокарте (16+ ГБ) бери умнее: `qwen2.5-coder:14b` или `:32b`.

**4. (Опционально) ключ Claude для режима «умнее»:**
```powershell
$env:ANTHROPIC_API_KEY="sk-ant-..."
```

**5. Запусти:**
```powershell
npm run copilot        # CLI в терминале
npm run copilot:web    # веб-панель → http://localhost:4000
```

Готово — основная работа идёт локально и бесплатно. Для сложной задачи в CLI
пиши `/hard <запрос>`, в вебе — включи «🧠 умнее».

## Ключи один раз — файл .copilot.env

Чтобы не вводить ключи в терминале каждый раз, создай в корне проекта файл
`.copilot.env` (шаблон — `copilot/.copilot.env.example`):

```
COPILOT_PROVIDER=groq
GROQ_API_KEY=gsk_...
COPILOT_STRONG=deepseek
DEEPSEEK_API_KEY=sk-...
```

Ассистент подхватит его при запуске. Файл в `.gitignore` — ключи не коммитятся.
Переменные, заданные в терминале, имеют приоритет над файлом.

## Настройки (переменные окружения)

В PowerShell задаются так: `$env:ИМЯ="значение"`.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `COPILOT_PROVIDER` | `ollama` | Основной провайдер: `ollama` / `deepseek` / `groq` / `openrouter` / `anthropic` / `openai` |
| `COPILOT_MODEL` | по провайдеру | Модель основного провайдера |
| `COPILOT_STRONG` | `anthropic` | Сильный провайдер для `/hard` и «умнее» |
| `COPILOT_BASE_URL` | — | Свой OpenAI-совместимый эндпоинт (LM Studio и т.п.) |
| `COPILOT_API_KEY` | — | Ключ для дешёвого API (DeepSeek/Groq/OpenRouter) |
| `ANTHROPIC_API_KEY` | — | Ключ Claude (для режима «умнее») |
| `COPILOT_PORT` | `4000` | Порт веб-панели |
| `COPILOT_ALLOW_DANGER` | — | `1` — разрешить разрушительные команды (по умолчанию блокируются) |

Ассистент умеет: читать/править/создавать файлы, искать по коду, запускать
команды и тесты, **искать в интернете** (`web_search`) и **читать страницы**
(`fetch_url`), **генерировать картинки**, помнить между сессиями. Разрушительные
команды (`rm -rf`, `format`, `git push --force`) блокируются, пока не задашь
`COPILOT_ALLOW_DANGER=1` — как подтверждение опасных действий у Codex.

### Ещё дешевле, чем Claude, но умнее локальной

Вместо Claude в режиме «умнее» можно поставить дешёвый API:
```powershell
$env:COPILOT_STRONG="deepseek"
$env:DEEPSEEK_API_KEY="..."
```
DeepSeek / Groq / OpenRouter стоят копейки за токены и заметно сильнее мелкой
локальной модели.

## Как устроено

```
copilot/
  core/
    providers.js  Реестр «мозгов»: ollama / anthropic / deepseek / groq / ...
    client.js     Провайдер Claude (Anthropic API, стриминг)
    openai.js     OpenAI-совместимый провайдер (Ollama, DeepSeek, Groq, ...)
    tools.js      Инструменты: read/write/edit/list/search/bash (в пределах проекта)
    agent.js      Агентный цикл: думает → инструмент → результат → повтор
  cli.js          Терминальный REPL (/hard — умнее, /reset, /exit)
  server.js       Веб-панель (HTTP + SSE-стриминг)
  web/index.html  Чат с переключателем «умнее»
```

## Генерация картинок (бесплатно)

Ассистент умеет генерировать изображения по описанию — бесплатно, без ключа и
подписки (через сервис Pollinations). Просто попроси:

> сгенерируй картинку: рыжий кот-программист в очках, digital art

Картинка сохранится в папку `generated/` и покажется прямо в веб-панели.
Описание лучше писать по-английски — качество выше. Сервис настраивается через
`COPILOT_IMAGE_BASE` (можно подключить другой prompt-in-URL сервис).

## Долговременная память

Ассистент запоминает важное между сессиями (предпочтения, соглашения проекта,
решения) в файле `.copilot-memory.md` и опирается на это в будущем. Скажи
«запомни, что …» или «забудь про …». Память локальна и не коммитится.

## Инструкции проекта (как AGENTS.md у Codex)

Создай в корне проекта файл `AGENTS.md` (или `COPILOT.md`) с правилами: стиль
кода, как запускать тесты, что нельзя трогать. Ассистент прочитает его и будет
следовать — как Codex следует `AGENTS.md`.

Многошаговые и длинные задачи ассистент ведёт сам: старые результаты
инструментов сворачиваются автоматически, чтобы не упираться в лимит токенов.
